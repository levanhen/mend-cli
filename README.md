mend — one CLI that applies the edits AI models write, in four formats (unified diff, SEARCH/REPLACE, V4A, JSON edits), with tiered line matching and atomic all-or-nothing file writes. Node 22 and its standard library alone.

## Run it

```sh
node main.ts [options] [PATCH]
```

- `check.ts` + the kit's `program/generator/practice.json` = the 100 public practice checks; the scored checks come from a hidden pool drawn the same way.
